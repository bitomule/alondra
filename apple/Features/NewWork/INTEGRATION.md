# F4 integration contract

This branch owns `AlondraNewWorkFeature` only. H connects the iOS and Mac screens and owns `apple/BUILD.bazel`, roots, and `FleetView.swift`.

1. Add `//apple/Features/NewWork:AlondraNewWorkFeature` to the iOS and Mac app entry targets. Create one `StoreOf<NewRequestFeature>` per iOS New scene or Mac New sheet. Send `.identityChanged` on a server/signing identity change or scene teardown; this cancels project, catalog, issue and submit effects and clears the draft. Each Mac window keeps its own store and its existing `MacWindowFeature.canSubmitNewRequest` origin guard.
2. Install `NewWorkOperations` at each composition root. `projects`, `options`, and `issues` adapt the corresponding service reads. `captureSubmissionScope` returns one immutable `NewWorkSubmissionScope` whose upload and create closures capture the **same fixed client, server URL, device and signer revision**. Do not read `fleet.client` again inside either closure. `isCurrent` compares that captured identity to the active identity. `NewWorkSubmissionScope` checks cancellation and identity before each upload and again just before create; its `create` closure must repeat the identity check at the transport dispatch boundary, then send through its captured client. The `create` closure calls `POST /v1/requests` exactly once and returns `.confirmed` for acknowledgement, `.failed(message)` for a definite rejection (including 401/403/409), or `.uncertain(message)` for timeout, lost response, cancellation after dispatch or any error that cannot prove rejection. The service signs at the point of I/O and never retries this POST without a backend idempotency contract.
3. Replace `WorkOptionsModel` and `IssuesModel` in `NewRequestView` and `NewRequestSheet` with `NewRequestFeature.State`. Views dispatch `.appeared`, `.projectSelected`, `.optionSelected`, `.issueSelected`, `.issuesOpened`, `.issuesRefreshRequested`, and `.issueQueryChanged`. Render `selection.specs`, `selection.current`, `projects`, `visibleIssues`, `pastedIssue`, loading and errors directly. Disable send while `isLoadingOptions`. The existing `NewWorkSelection` rule keeps the selected issue when its repo selects a matching checkout, drops old option overrides after a project switch, rejects values missing from the current catalog, and leaves server defaults (including automatic effort) implicit in the body.
4. Platform file pickers prepare files with `AttachmentFile.prepare`, enforce the existing 20 MB limit, then send `.attachmentAdded(NewRequestAttachment(id:name:data:))`. Render the attachment list from feature state and remove with `.attachmentRemoved`; keep thumbnails as derived view data, not request state. On submit, `CreateRequestUseCase` uploads in order, then sends the body containing the stored IDs. A failed upload leaves the draft and does not call `create`. The feature rejects a second submit while the first is in flight.
5. An acknowledged POST increments `successfulSubmissionCount` once, clears text and attachments, and drives iOS success feedback or Mac sheet dismissal. A POST error is `submissionUncertain`: keep the draft, show the message, and disable repeat submission. Offer an explicit “Start another request” action that sends `.discardUncertainDraft` only after the user checks Sent; never label a timeout as a definite failure. Neither `NewRequestView` nor `NewRequestSheet` should retain `AlondraClient`, `FleetStore.perform`, `Task` based network calls, or a local `sending`/`WorkOptionsModel`/`IssuesModel` state. Preserve each platform's existing layout, localization and accessibility wording.
6. H verifies both app builds and uses MAV to submit a request with a project, issue, default auto effort and attachment; verify the server receives one request and the UI clears once. Also exercise a stale catalog response after switching projects and a lost POST acknowledgement. The feature tests alone do not prove root composition or live upload behavior.

This use case is UI independent and can later be composed for an App Intent. No Intent target is added here.
