# SyncSession integration handoff

`//apple/Data/Sync:AlondraSync` owns one overview/changes loop per actor instance. The existing `AlondraAPIClient` initializer keeps the local daemon wire. `SyncTransport` also accepts a relay service adapter that supplies decrypted, verified overview bytes and waits on its own relay revision/epoch cursor; it must not treat the local overview `tick` as a relay cursor. The application root keeps one `SyncSession` per active server/device/credential identity and gives all scenes or windows streams from that actor. Each window retains its own selection and drafts.

`SyncSession.subscribe()` returns an `AsyncStream<SyncState>`. Each value contains its `identity`, `generation`, `publicationRevision`, `connection`, and complete `snapshot` together. A refetch increments `publicationRevision` even if the body is identical; all scenes see the same value for that emission. Decode `SyncState.snapshot?.body` into the current `Overview` DTO in the presentation adapter. A new subscriber receives the current complete state, including the last snapshot during an offline interval. Rendering should replace the prior state with each value; a slow window can safely skip intermediate values without retaining a snapshot from another identity. `stop()` finishes subscriptions and cancels the in-flight poll. The last subscriber's termination also cancels it. Calling `use(transport:identity:isUnauthorized:)` or the local-client convenience clears the retained snapshot, increments the generation, resets to connecting, and starts a fresh overview for existing subscribers. The caller must change `credentialRevision` on account/Mac/key rotation even if `deviceID` remains unchanged.

Every overview response is treated as a complete snapshot, including a lower local tick after daemon restart. The actor never merges snapshots. Each change wait is bounded to 10 seconds and triggers a new full overview after a timeout. The generation check prevents an old server or signer response from reaching the stream after `use`. A relay adapter must enforce its own epoch, revision, request-ID, Mac signature, and response-envelope ordering before returning plaintext. The injected `isUnauthorized` classifier maps a failed relay bearer/device challenge to `.unpaired`; never attach that bearer to the local `AlondraAPIClient`.

The module tests exercise local and alternate transports with two subscribers and one poll. The application root must still share one session across windows; the real relay adapter and physical-device path are separate H gates.

No app root or `apple/BUILD.bazel` was modified in this branch.
