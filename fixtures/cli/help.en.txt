Usage: alondra [OPTIONS] [COMMAND]

With no command, opens the terminal app — or sets up this Mac, the first time.

Set up
  doctor       Check everything; --fix repairs or finishes the setup
  update       Install the newest release
  config       Show or change settings  (list · get · set · unset)

Daily
  status       Questions and tasks, as text
  answer       Answer a question
  send         Send a message to a task or the orchestrator
  cancel       Cancel tasks

Devices and Macs
  device       Devices that use a Mac  (list · approve · deny · remove · invite)
  mac          The Macs this terminal uses  (list · connect · forget · ping · reset-identity)
  account      Your Alondra account  (status · login · logout)
  accounts     The Claude accounts nodes may run on  (list · add · login · enable · disable · remove)
  relay        Notifications and access away from home  (status · on · off)

More
  cleanup · handover · models · state · delivery · orchestrator      (alondra help more)

Options: --json  --no-input  -V, --version  -h, --help
